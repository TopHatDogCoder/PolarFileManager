# PolarFileManager
A file manager in Python i made.
# Requirements
Python 3.6 (2016) or newer
OS: Windows Vista (2007) or newer, macOS 10.9 Mavericks (2013) or newer, Any Linux distribution that has glibc 2.17 or newer (2012 or newer).
No extra libraries needed! (However you can optionally use the send2trash package)
